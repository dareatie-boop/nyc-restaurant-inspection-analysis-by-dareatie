# NYC-restaurants-inspection-analysis-by-dareatie
**Project Overview**

This project analyses New York City restaurant inspection data to identify patterns in inspection outcomes, violations, restaurant grades, and differences across boroughs.

The project demonstrates the application of SQL and Power BI to data cleaning, exploratory data analysis, KPI development, and dashboard visualization.

**Objectives**

Analyse restaurant inspection outcomes across NYC boroughs.

Identify common and critical health code violations.

Examine restaurant grades and inspection score patterns.

Compare cuisine categories using inspection data.

Present findings through Power BI visualizations.

**Tools Used**

Microsoft Excel — data preparation and cleaning

MySQL 8.0 — data validation, querying, and analysis

Microsoft Power BI — dashboard development and visualization

**Dataset**

The project uses public NYC restaurant inspection data.

Dataset source: NYC Open Data

Approximately 288,883 rows were imported into MySQL during the project workflow. The final dataset size and cleaning decisions will be documented alongside the analysis.

**Analysis Workflow**

Data preparation and cleaning.

Importing data into MySQL.

Validating records and checking data quality.

Writing SQL queries to answer business questions.

Developing a Power BI dashboard.

Interpreting findings and proposing recommendations.
